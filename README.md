### ∴ How I think

> **Lemma 1.** A bug is not the problem — it is a *symptom* of an assumption nobody questioned.
>
> **Lemma 2.** A vulnerability is a side effect of **context**: the same code is safe in one world and fatal in another.
>
> **Corollary.** I care less about *what* breaks, and more about *why it becomes useful*. &nbsp;∎
